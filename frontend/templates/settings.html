Шаблоны уведомлений

Шаблон для уведомлений о занятиях. Доступные переменные:
{group_name} - название группы
{time} - время занятия
{days} - дни недели
{additional_text} - дополнительный текст (опционально)
Шаблон для уведомлений о вознаграждениях. Доступные переменные:
{reward_name} - название вознаграждения
{points} - количество баллов
{total_points} - всего баллов за месяц
{reason} - примечание (опционально)
Шаблон для уведомлений о карточках. Доступные переменные:
{card_name} - название карточки
{reason} - причина выдачи
Шаблон для уведомлений об оплате. Доступные переменные:
{full_name} - ФИО ученика
{payment_date} - дата оплаты
{month} - месяц оплаты
{payment_type} - тип оплаты (Наличные, Карта, Click, Payme, Uzum)
{amount_paid} - сумма оплаты
{debt_info} - информация о долге (отображается только если есть долг)

Блокировка должников

Для рассрочки выберите частичную оплату. Для старых долгов, которые родители догоняют сейчас, выберите любую оплату в этом календарном месяце.
Ежедневная сверка всего списка по времени Ташкента. Обычные изменения отправляются сразу отдельной командой.
Ускоряет полную синхронизацию. Внутри каждого терминала записи всё равно идут по очереди.
При полной синхронизации bridge удалит старые numeric-ID записи, оставшиеся после удаления ученика или сотрудника.
Старые спорные долги до этой даты не блокируют вход.
